# EverySpool v1 launch

**v1:** the manual calculator. **Target launch:** October 16–23, 2026.
**90-day goal:** 100 monthly visitors and 1 purchase through an EverySpool link.

## Before launch (this week)
- [ ] Buy everyspool.com on Cloudflare
- [ ] Turn on two-factor login for GitHub, Cloudflare, and Ko-fi
- [ ] Create the `everyspool` repo, upload everything, and turn on Pages (Source: GitHub Actions)
- [ ] Run **Actions → Render brand images**
- [ ] Connect the domain (README → Custom domain) and turn on Enforce HTTPS
- [ ] Set up hello@everyspool.com forwarding
- [ ] Create the Ko-fi page and paste its link into `assets/app.js`
- [ ] Create the GoatCounter site and replace `YOURCODE` in both pages
- [ ] Fill in `repo` in `assets/app.js` and `.github/FUNDING.yml`
- [ ] Claim "EverySpool" on Reddit, Printables, MakerWorld, YouTube, and Instagram
- [ ] Run the USPTO trademark search for "EverySpool"
- [ ] Spot-check PLA, PETG, and ABS densities against 2–3 brands' spec sheets

## Launch day checks
- [ ] Site loads at everyspool.com on a phone and a computer, in light and dark mode
- [ ] A test calculation gives the right answer (try 1,000 g on a 1 kg spool: should be 1 spool)
- [ ] Share link opens with the same entries
- [ ] Pasting the link into Discord or a text shows the preview image
- [ ] "Buy me a spool" opens Ko-fi; "Suggest a feature" opens the issue forms
- [ ] GoatCounter shows your own visit

## Soft launch (first two weeks)
- [ ] Share in 2–3 printer Discord servers
- [ ] Answer "how much filament do I need" questions on Reddit with a share link
- [ ] Note every question and suggestion as an issue

## After launch
- [ ] Apply to Amazon Associates once the site has steady visits; then set `shopUrl`
- [ ] Build G-code upload
- [ ] Big launch post on r/3Dprinting with the G-code feature
- [ ] 90-day check-in (around January 20, 2027): visitors, purchases, and what people asked for
