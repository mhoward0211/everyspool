# Contributing

Thanks for helping out.

**Easiest way to help:** add or fix a material. Edit `assets/materials.js` right on GitHub (click the pencil icon), add a line like `"PETG-CF": 1.29,`, and open a pull request with a link to the spec sheet. Tests run automatically and catch typos.

**Found a wrong number?** Open a "Report a wrong result" issue and include the share link from the calculator.

**Want to change code?** Open a Codespace, make your change, run `npm test`, and open a pull request. If you change the math in `calc.js`, add a test in `tests/calc.test.js`.
